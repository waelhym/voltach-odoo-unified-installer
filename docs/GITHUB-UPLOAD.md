# GitHub Repository

Repository:

`https://github.com/waelhym/voltach-odoo-unified-installer`

Clone:

```bash
git clone https://github.com/waelhym/voltach-odoo-unified-installer.git
cd voltach-odoo-unified-installer
```

To push local changes:

```bash
git add .
git commit -m "Update unified Odoo installer"
git push
```

Never commit real passwords, generated `.env` credentials, database dumps, certificates, filestore data or production backups.
